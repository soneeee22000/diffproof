### O3 · Plan review and amendment A1 (2026-11-17)

- An outside design review (kept private) found five issues to fix before scaffolding: test
  verdicts that treated execution errors as behaviour, evidence checks that accepted empty or cross-agent evidence, an
  incomplete trusted-runner boundary, a spend cap checked only after responses, and a volatile guard that would reject
  real repository content. It also recommended a single-agent baseline, narrower metric claims and a smaller first
  release.
- All of it was applied as SPEC amendment A1, with ADR-0004, 0006 and 0007 revised and ADR-0008 added. Owner choices:
  hard spend cap via reservation; GitLab as the v0.2.0 milestone; the repository stays in its current folder.
- Gate caps were re-estimated from ticket sums plus 25% for integration and fixes.
