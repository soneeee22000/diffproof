# Gate G4: GitHub integration (v0.1-dev)

- Status: not started. Opens when G3 §7 evidence exists.
- Cap: 0.75 day (timebox; was 0.5 day for both forges before A1)
- Branch: `feat/g4-github`

## 1. Scope

- One frozen snapshot per PR: merge-base and head SHAs, the diff, `git archive` trees and comment coordinates all from
  that pair, plus a head-moved check before publishing.
- The GitHub adapter, the composite Action and the example workflow, with diffproof running from a pinned, trusted
  revision and the PR checkout treated as data.
- A **real PR** in this repository shows the bot's review comments and test-execution evidence.

GitLab moved to v0.2.0 (G7) under amendment A1. From this gate on, the repository's own PRs can be reviewed by the bot.

## 2. Decisions taken before the gate

| #   | Decision                                                                                                                 | Where               |
| --- | ------------------------------------------------------------------------------------------------------------------------ | ------------------- |
| D1  | COMMENT-only publishing; no approve, merge or push path                                                                  | ADR-0005            |
| D2  | Trigger: same-repo PRs carrying the `diffproof` label, or `workflow_dispatch`. A trigger policy, not a trust boundary    | SPEC §9.5           |
| D3  | diffproof runs from `uses: soneeee22000/diffproof@<sha>`, never `./`; PR checkout with `persist-credentials: false` [A1] | SPEC §9.5, ADR-0007 |
| D4 | The GitHub repository is public from the design phase (2026-11-17); the README states that nothing is built yet | G6-T4 |

### G4-T1: Snapshot freezing and git commands

- **Requirements:** FR-19, SEC-01, SEC-09
- **Tests first:** `tests/test_snapshot.py::test_base_sha_is_the_merge_base`,
  `::test_diff_and_trees_come_from_the_same_sha_pair`, `::test_archive_trees_have_no_git_metadata`,
  `::test_non_hex_sha_is_rejected_before_any_git_call`;
  `tests/test_gitcmd.py::test_git_commands_use_fixed_argument_lists`.
- **Acceptance:** `forge/snapshot.py` builds a `Snapshot` and materializes both trees with `git archive`;
  `forge/gitcmd.py` is the only non-sandbox module that imports `subprocess`, with SHAs validated as 40 hex
  characters. Tested against a throwaway local repository created in the test.
- **Files:** `src/diffproof/forge/{snapshot,gitcmd}.py`, the tests above.

### G4-T2: GitHub adapter with `commit_id` and head-moved check

- **Requirements:** FR-12, FR-19, SEC-03
- **Tests first:** `tests/test_github_adapter.py::test_review_payload_uses_comment_event_right_side_and_commit_id`,
  `::test_context_is_loaded_from_event_file`, `::test_moved_head_posts_no_inline_comments_and_marks_stale`,
  `::test_permission_error_falls_back_to_job_summary`, `::test_comment_outside_diff_never_reaches_the_api`.
- **Acceptance:** `httpx` client. Payloads match the G0-T5 shapes, tested with `respx` fixtures. Every comment is
  anchored to the snapshot's head SHA. On a 403 the adapter writes to `$GITHUB_STEP_SUMMARY`.
- **Files:** `src/diffproof/forge/github.py`, `tests/test_github_adapter.py`, `tests/fixtures/github/`.

### G4-T3: Composite Action and example workflow from a trusted revision

- **Requirements:** FR-15, SEC-04, SEC-02, SEC-09
- **Tests first:** `tests/test_workflow_policy.py::test_triggers_are_labeled_synchronize_and_dispatch_only`,
  `::test_job_requires_same_repo_and_label`, `::test_permissions_are_least_privilege`,
  `::test_every_action_is_pinned_by_full_sha`, `::test_diffproof_is_used_by_pinned_sha_never_local_path`,
  `::test_pr_checkout_does_not_persist_credentials`, `::test_api_key_is_set_only_on_the_diffproof_step`,
  `::test_action_installs_from_its_own_path`, `::test_generated_tests_run_in_docker_sandbox`.
- **Acceptance:** `action.yml` (composite) and `.github/workflows/diffproof.yml` meet every SPEC §9.5 property, and
  the test asserts each one. `README` and SPEC §9.5 note the workflow-file residual risk.
- **Files:** `action.yml`, `.github/workflows/diffproof.yml`, `tests/test_workflow_policy.py`.

### G4-T4: Private repo, secret, live demo PR

- **Requirements:** DEL-02, FR-19
- **Tests first:** none (live demonstration). The workflow run is the evidence.
- **Acceptance:**
  - **Owner** adds the `ANTHROPIC_API_KEY` repository secret.
  - The workflow references a pinned commit on `develop` that predates the demo PR.
  - A PR with a seeded off-by-one plus a benign decoy edit is labelled `diffproof`.
  - The bot posts a COMMENT review with at least one inline finding and the test verdicts with their run evidence.
  - The run URL and a screenshot are saved to `docs/media/demo-pr.png`; spend is reconciled against the Console.
- **Files:** `docs/media/demo-pr.png`, §5 of this sheet.
