# Gate G2: deterministic core (v0.1-dev)

- Status: not started. Opens when G1 §7 evidence exists.
- Cap: 2 days (timebox; was 0.75 day before A1, against 465 minutes of ticket estimates)
- Branch: `feat/g2-core`

## 1. Scope

Build the parts that judge the agents **before** the agents exist:

- the diff parser that defines which lines are "in the diff";
- detectors D1a, D1b (per-agent evidence binding), D2a, D2b, D3, D4 and D5;
- the sandbox with its trust boundary, per-test outcomes from pytest reports, and the execution-aware verdict with
  flake detection;
- sandbox record and replay;
- mutant agents and the harness check that proves every detector fires, and that the documented limits stay true.

Everything here is pure code and costs $0. The agents built in G3 plug into a gate that is already tested.

## 2. Decisions taken before the gate

| #   | Decision                                                                                                        | Where               |
| --- | --------------------------------------------------------------------------------------------------------------- | ------------------- |
| D1  | Gate before agents: the oracle is built before the thing it judges                                              | ADR-0003            |
| D2  | Detector framework ported from faultline, extended with location and message                                    | SPEC §7.1           |
| D3  | The injection scan is a heuristic; nothing structural depends on it                                             | SPEC §7.3, §11      |
| D4  | Docker tests run on ubuntu CI only; local Windows uses `LocalSandbox --trusted-local`                           | SPEC §8, G0-T6      |
| D5  | Behavioural verdicts only when a test executed on both trees; outcomes come from JUnit XML, not exit codes [A1] | SPEC §7.6, ADR-0004 |
| D6  | Evidence is bound to the producing agent's own tool calls; warning+ findings need evidence [A1]                 | SPEC §7.2           |
