# Gate G5: benchmark and evidence (v0.1-dev)

- Status: not started. Opens when G4 §7 evidence exists.
- Cap: 1.75 days (timebox; was 0.75 day before A1)
- Branch: `feat/g5-bench`

## 1. Scope

Measure every claim the v0.1.0 README will make, on one package:

- the self-authored `intervals` package with held-out oracle tests;
- seeded AST mutants, keeping only those the oracle suite kills (no equivalence claim for the rest);
- synthetic bug PRs with decoy edits, clean PRs, and paired injection twins with canaries, split into W1-dev (tuning)
  and W1-eval (headline numbers, recorded once after the prompts are frozen);
- a single-agent baseline with the same model, tools, budget and gate;
- metrics under the SPEC §10.4 reporting rules, plus a gate-on vs gate-off ablation;
- `RESULTS.md` generated by code, regenerated keyless in CI, and the recorded tests re-executed in Docker.

W2 (two more packages) and real historical changes moved to v0.2.0 (G7) under amendment A1.

## 2. Decisions taken before the gate

| #   | Decision                                                                                                            | Where                       |
| --- | ------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| D1  | Decoy edits are mandatory, so localization is not trivial                                                           | SPEC §10.3                  |
| D2  | Oracle tests never enter a workspace or prompt                                                                      | SEC-07                      |
| D3  | The bug span is the mutated AST node's new-side lines; no fuzzy tolerance; the precision metric is labelled spatial | traceability, "Ambiguities" |

| D6  | Misses are listed by case id; the corpus is disclosed as self-authored                                              | SPEC §0.2                   |

## 3. Tickets

> **TDD.** Each ticket starts with its failing tests, marked `@pytest.mark.req("<ID>")`.
>
> **Paid-run rule.** One case, then five, then the set. Cassettes are committed the moment a run finishes. The session
> budget is passed with `--budget-usd`; the ledger refuses any request whose reservation would pass $30 in total.
>
> **Stop rule.** If a recording run fails twice for the same class of reason, stop: a replayable iteration layer is
> missing. Build it before recording again.
