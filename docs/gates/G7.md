## 1. Scope

The next milestone after v0.1.0. GitLab comes first because it matters for the target role:

- the GitLab adapter, CI template and a **real MR** on gitlab.com;
- the docs agent, using the shared definitions from G3-T6;
- W2: two more corpus packages, reported on their own and pooled with W1-eval;
- three to five real historical Python changes, reported separately from the synthetic corpus.

Nothing here is claimed in the README until its live evidence exists.
