## 1. Scope

The thinnest end-to-end path, with every quality gate already enforced:

- the repository exists with the full toolchain, and CI is green;
- `diffproof review --diff fixture.patch` runs the whole graph keyless with stub nodes and writes `review.json`;
- record/replay, the pre-dispatch spend ledger and the scoped volatile guard work, proven by one real recorded smoke
  cassette;
- `trace_check` enforces requirement markers from day one.

No real agents and no detectors yet. Stubs return fixed values.
