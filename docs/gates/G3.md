# Gate G3: agents and the MCP tool boundary (v0.1-dev)

- Status: not started. Opens when G2 §7 evidence exists.
- Cap: 1.5 days (timebox; was 0.75 day before A1)
- Branch: `feat/g3-agents`

## 1. Scope

- The MCP server with exactly four repository tools, and the bridge that turns them into Anthropic tool definitions
  while recording a per-agent `RunTrace` with deterministic call ids.
- The Anthropic adapter on `claude-opus-5-5`, behind the G1 transport and spend ledger.
- The reviewer and test-writer agents, one set of code definitions for routing and targets, the deterministic router
  with `Send` fan-out, canonical fan-in ordering, the bounded repair loop, and the gate and publish wiring.
- One real end-to-end cassette on a fixture PR.

The docs agent moved to v0.2.0 (G7) under amendment A1. Every node is unit-tested with `ScriptedTransport`; only G3-T8
spends money.

## 2. Decisions taken before the gate

| #   | Decision                                                                                                                           | Where               |
| --- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------- |
| D1  | Routing is deterministic; no model decides control flow                                                                            | ADR-0001, SPEC §4.3 |
| D2  | Agents see the repository only through MCP tools; the prompt's diff is itself a traced `get_diff` result in that agent's own trace | ADR-0002, SPEC §5   |
| D3  | Typed agent output via structured outputs, or a local `submit_result` finalization tool, per G0-T4                                 | SPEC §5.4           |
| D4  | Untrusted text only inside `<untrusted>` blocks; prompts are snapshot-tested                                                       | SPEC §5.5           |
| D5  | One set of definitions (changed function, public definition, changed public signature), computed with `ast.parse` [A1]             | SPEC §4.3           |

### G3-T1: MCP server with four tools and guards

- **Requirements:** FR-08, SEC-05, CON-03
- **Tests first:** `tests/test_mcp_server.py::test_server_exposes_exactly_four_tools`,
  `::test_parent_segments_and_absolute_paths_are_rejected`, `::test_symlink_escaping_the_root_is_rejected`,
  `::test_read_span_and_file_size_caps_apply`, `::test_search_is_literal_not_regex`,
  `::test_every_result_carries_a_call_id_and_line_refs`.
- **Acceptance:** a FastMCP server (import path from G0-T3) over stdio, with the SPEC §5.2 tool table, guards and
  constants. It reads PR files as data and never imports them. `run_tests` delegates to `SandboxPort`.
  `diffproof serve-mcp --root DIR` starts it.
- **Files:** `src/diffproof/tools/{mcp_server,workspace}.py`, `tests/test_mcp_server.py`.

### G3-T2: MCP → Anthropic bridge, per-agent `RunTrace`, call ids

- **Requirements:** FR-08, GATE-02, GATE-05
- **Tests first:** `tests/test_bridge.py::test_mcp_schemas_become_strict_anthropic_tools`,
  `::test_every_tool_call_is_recorded_with_agent_id_and_call_id`, `::test_call_ids_are_deterministic`,
  `::test_returned_to_contains_only_that_agents_refs`, `::test_unknown_tool_name_is_refused_and_recorded`.
- **Acceptance:** the bridge lists the server's tools, converts them, executes `tool_use` blocks through
  `ClientSession.call_tool`, and appends a `ToolCall` with `agent_id`, `call_id` and `returned_refs`. An unknown tool
  name is refused, and that refusal feeds D3.
- **Files:** `src/diffproof/tools/bridge.py`, `tests/test_bridge.py`.

### G3-T3: Anthropic adapter

- **Requirements:** CON-02, FR-17, NFR-08, GATE-07
- **Tests first:** `tests/test_anthropic_adapter.py::test_requests_carry_no_sampling_parameters`,
  `::test_requests_never_force_tool_choice`, `::test_every_request_sets_max_tokens_from_profile`,
  `::test_request_is_admitted_by_ledger_before_dispatch`, `::test_refusal_is_recorded_as_declined_agent`,
  `::test_usage_settles_the_reservation`, `::test_effort_comes_from_model_profiles`.
- **Acceptance:**
  - Builds Messages requests for `claude-opus-5-5` with per-agent effort and `max_tokens` from `MODEL_PROFILES`.
  - Prompt caching is set on the system prompt and tools.
  - Server-side fallbacks are configured as G0-T4 documented.
  - Requests go through the G1 `Transport` and `SpendLedger`, so record, replay and the hard cap all work.
- **Files:** `src/diffproof/model/{anthropic_adapter,profiles}.py`, `tests/test_anthropic_adapter.py`.

### G3-T4: Reviewer agent

- **Requirements:** FR-05, SEC-06
- **Tests first:** `tests/test_reviewer.py::test_returns_typed_findings_from_scripted_model`,
  `::test_findings_cite_evidence_by_call_id`, `::test_untrusted_text_is_wrapped_in_data_blocks`,
  `::test_system_prompt_declares_untrusted_blocks_as_data`, `::test_prompt_snapshot_is_stable`,
  `::test_tool_loop_stops_at_max_turns`.
- **Acceptance:** a bounded tool loop (`MAX_TOOL_TURNS = 8`) ending in a `list[Finding]`. The prompt lives in
  `agents/prompts/reviewer.md` and asks for evidence as `(call_id, path, line, side)`. Harness-generated prompt parts
  pass the volatile guard.
- **Files:** `src/diffproof/agents/{loop,reviewer}.py`, `src/diffproof/agents/prompts/reviewer.md`,
  `tests/test_reviewer.py`.

### G3-T5: Test-writer agent and repair round

- **Requirements:** FR-06, FR-10
- **Tests first:** `tests/test_test_writer.py::test_targets_only_changed_functions`,
  `::test_generated_module_paths_are_under_tests`, `::test_repair_receives_normalized_run_outcomes`;
  `tests/test_graph.py::test_repair_happens_at_most_once`.
- **Acceptance:** emits `GeneratedTest` objects whose targets are changed functions (G3-T6). INVALID tests get one
  repair round with the sandbox outcomes; anything still INVALID is dropped and counted.
- **Files:** `src/diffproof/agents/test_writer.py`, `src/diffproof/agents/prompts/test_writer.md`,
  `tests/test_test_writer.py`.

### G3-T6: Code definitions module

- **Requirements:** FR-03, FR-06
- **Tests first:** `tests/test_definitions.py::test_changed_function_needs_an_added_line_in_its_span`,
