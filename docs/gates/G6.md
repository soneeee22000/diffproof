# Gate G6: release v0.1.0

- Status: not started. Opens when G5 §7 evidence exists. (It can be pulled forward to right after G4 if a release is
  needed sooner; the benchmark then ships as v0.1.1, and the README makes no benchmark claim until it does.)
- Cap: 0.5 day (timebox; was 0.25 day before A1)
- Branch: `release/v0.1.0`

## 1. Scope

Release v0.1.0 on the public repository, honestly:

- a README a stranger can follow, with its claims backed by committed artifacts;
- an independent code and security review, with its findings fixed;
- no stray tool or editor files, and clean commit authorship;
- a CHANGELOG, the `v0.1.0` tag and GitHub release, and a check that every link works.

### G6-T1: README and claims scan

- **Requirements:** DEL-01, CON-05
- **Tests first:** `tests/test_claims.py::test_public_docs_contain_no_banned_wording`,
  `::test_readme_numbers_match_results_json`.
- **Acceptance:** the README includes:
  - what the project is and is not, with SPEC §1.3 non-goals
  - the architecture diagram
  - a quickstart: replay mode needs no key
  - the demo PR screenshot with its link
  - "What the checks establish, and what they do not" (SPEC §0.1a), and the measured cost per PR
  - the release scope (SPEC §1.2a), with GitLab, the docs agent and W2 listed as v0.2.0
  - a results excerpt generated from `results.json`
  - prior art (SPEC §1.4)
  - the honest-scope paragraph

  The banned-wording list lives in the test file.

- **Files:** `README.md`, `tests/test_claims.py`.

### G6-T2: Code review and security review; fix findings

- **Requirements:** SEC-03, SEC-04, SEC-05, SEC-02
- **Tests first:** each confirmed finding gets a failing regression test before its fix.
- **Acceptance:** a full-repo code review and a security review covering the SPEC §11 threat table. Every finding is
  fixed or written up in §6 with a reason. Lint, types and tests are green.
- **Files:** as findings require; §6 of this sheet.

### G6-T3: Repository hygiene; check commit authorship

- **Requirements:** CON-01
- **Tests first:** none. Verified by `git ls-files` and `git log --format='%an %ae %(trailers)'`.
- **Acceptance:**
  - No editor or tool directories, stray logs or scratch screenshots tracked.
  - All commits authored by the owner.
- **Files:** `.gitignore` if needed.

### G6-T4: CHANGELOG, tag, release, link check

- **Requirements:** DEL-05, DEL-01, CON-01
- **Tests first:** none. Verified by the link check output in §5.
- **Acceptance:**
  - `CHANGELOG.md` in Keep a Changelog format.
  - `develop` squash-merged to `main`, and `v0.1.0` tagged.
  - The repository is already public (since 2026-11-17); the GitHub release is published from the tag.
  - Every URL in README and docs returns 200 and shows the expected content (title or page check, not just status).
- **Files:** `CHANGELOG.md`, §5 of this sheet.
